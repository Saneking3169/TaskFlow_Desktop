# TaskFlow_Desktop

## Scopul aplicației
TaskFlow este un prototip al unei aplicații desktop de tip **Task Manager / To-Do List**. Instrumentul permite utilizatorilor să **adauge sarcini**, să **vizualizeze lista de sarcini**, să **caute** și să **prioritizeze** sarcinile (prioritate mică / medie / mare), precum și să le **marcheze ca finalizate** sau să le **șteargă**. Datele sunt legate de contul utilizatorului și se sincronizează între dispozitive.
