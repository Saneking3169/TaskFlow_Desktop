# Design — TaskFlow

Aici se adaugă capturile ecranelor din prototipul Figma și descrierea lor:

1. Autentificare / înregistrare
2. Fereastra principală (lista de sarcini)
3. Fereastra pentru crearea / editarea sarcinii
4. Calendar
5. Setări / profil

Sistem de design: Poppins (titluri) + Inter (text), culori #4F46E5 / #0F172A / #F59E0B, colțuri rotunjite 12 px / 8 px, grilă de 8 px.
